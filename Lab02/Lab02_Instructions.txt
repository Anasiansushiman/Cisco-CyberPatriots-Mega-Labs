Part 13: Configure ACLs for Security

Edge Router:
- Use ACL number 110 
- Deny any traffic coming from the Roommates' IP using the `host` keyword
- Allow all other traffic
- Apply this ACL for any incoming traffic from ports facing the public network

R3:
- Use an extended ACL named WORKERS
- Permit any icmp and tcp traffic coming from the 10.0.12.0/26 and 
10.0.12.64/26 networks bound for the Boss PC's public IP address (48.1.2.12)
- Permit any traffic coming from the 10.0.12.0/26 and 10.0.12.64/26 networks
bound for the Servers using the 'host' keyword for the servers
- If you would like to, you can explicitly deny all other traffic (not needed)
- Apply this ACL for any incoming traffic from the Money Manager/Workers
